Slack Integration

Optionally send newly created Stories/Tasks to a Slack Workflow Builder webhook (e.g. a "Front Request" workflow) right after creating them in Jira. If your team has set up a shared default webhook (via a local secrets.local.js file - not something from this Options page), you don't need to fill in the URL field below at all. Otherwise, paste your own webhook URL here to enable this feature.

Treat this URL as a secret - anyone with it can trigger your Slack workflow. Created in Slack via Workflow Builder → Add trigger → From a webhook.

Sent as the workflow's slack_id variable. Find yours in Slack via your profile → "..." menu → "Copy member ID". Note: manually typing <@slack_id> around the inserted variable in the message step does not work - Workflow Builder's composer escapes those characters as literal text instead of parsing them as a mention. To get a real clickable mention, the slack_id trigger variable's Data type must be changed to User (not Text) in the webhook trigger's settings, and then re-inserted into the message step using the variable picker (typing "/" or "@") rather than typed by hand - Workflow Builder will then format it correctly at send time.
